# RecepVoz visual assets v2

These assets are production-optimized WebP derivatives of the user-approved visual references for the frontend redesign.

## Usage rules
- Preserve transparent composition and avoid baking text into illustrations.
- Use as screen-specific hero/feature art; UI data and labels remain live HTML/React.
- Prefer subtle motion (float, glow, parallax) around the art rather than animating the raster itself.
- Respect prefers-reduced-motion.
- Do not reuse a screen-specific hero as a global generic icon unless explicitly approved.

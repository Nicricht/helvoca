Política de Privacidad

Última actualización: 22 de septiembre de 2026.

1. Qué es RecepVoz

RecepVoz es una plataforma de atención y automatización para negocios. Puede gestionar interacciones por voz, integrar canales de mensajería, apoyar reservas, pedidos, solicitudes y seguimiento de clientes. La plataforma tecnológica también puede identificarse internamente como Helvoca.

2. Datos que puede tratar

Dependiendo de cómo un negocio configure el servicio, RecepVoz puede tratar datos como nombre, teléfono, correo electrónico, contenido de conversaciones, reservas, pedidos, solicitudes y datos técnicos necesarios para operar y proteger la plataforma.

3. Para qué se usan los datos

  • Prestar las funciones contratadas por cada negocio.
  • Responder consultas y ejecutar acciones autorizadas, como registrar o modificar reservas.
  • Mantener seguridad, trazabilidad, auditoría y prevención de abuso.
  • Mejorar el funcionamiento técnico del servicio.

4. Proveedores tecnológicos

RecepVoz puede utilizar proveedores externos de infraestructura, comunicaciones e inteligencia artificial cuando sean necesarios para prestar el servicio. El uso de cada proveedor depende de la configuración activa del negocio.

5. Conservación y seguridad

Los datos se conservan durante el tiempo necesario para operar el servicio, cumplir obligaciones aplicables, mantener registros de seguridad o atender solicitudes legítimas. Se aplican controles técnicos y de acceso para reducir el riesgo de acceso no autorizado.

6. Derechos y consultas

Las personas pueden solicitar información, corrección o eliminación de datos cuando corresponda. Para consultas de privacidad o contacto comercial, puede utilizarse el teléfono +1 435 565 2512.

7. Cómo solicitar la eliminación de datos

Para solicitar la eliminación de datos personales tratados por RecepVoz, envía un correo a vozrecep@gmail.com con el asunto Solicitud de eliminación de datos - RecepVoz. Indica la información necesaria para localizar los datos, por ejemplo el número de teléfono o la cuenta con la que utilizaste el servicio. No envíes contraseñas, tokens, códigos de verificación ni otras credenciales.

Podemos solicitar información adicional únicamente para verificar que la solicitud corresponde a la persona o cuenta afectada. Una vez verificada, se eliminarán o anonimizarán los datos que corresponda, salvo aquellos que deban conservarse por obligaciones legales, seguridad, prevención de fraude, resolución de disputas u otras bases legítimas aplicables.

Si la solicitud se relaciona con una cuenta de Meta o WhatsApp conectada a RecepVoz, indícalo en el correo para identificar correctamente la integración asociada.

8. Cambios

Esta política puede actualizarse cuando cambien las funciones, proveedores o requisitos aplicables. La versión vigente se publicará siempre en este sitio.

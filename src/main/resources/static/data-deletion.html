Solicitud de eliminación de datos

Última actualización: 22 de septiembre de 2026.

Si utilizaste RecepVoz, interactuaste con un negocio atendido mediante RecepVoz o vinculaste una cuenta de Meta/WhatsApp con el servicio, puedes solicitar la eliminación de tus datos personales cuando corresponda.

Cómo solicitar la eliminación

  1. Envía un correo a vozrecep@gmail.com.
  2. Usa como asunto: Solicitud de eliminación de datos - RecepVoz.
  3. Indica la información necesaria para localizar tus datos, por ejemplo el número de teléfono o cuenta con la que utilizaste el servicio.
  4. No envíes contraseñas, tokens, códigos de verificación ni otras credenciales.

Verificación y procesamiento

Podemos solicitar información adicional únicamente para verificar que la solicitud corresponde a la persona o cuenta afectada. Una vez verificada, se eliminarán o anonimizarán los datos que corresponda, salvo aquellos que deban conservarse por obligaciones legales, seguridad, prevención de fraude, resolución de disputas u otras bases legítimas aplicables.

Datos de Meta y WhatsApp

Si la solicitud se relaciona con una cuenta de Meta o WhatsApp conectada a RecepVoz, indica esa circunstancia en el correo para poder identificar correctamente la integración asociada.

Contacto

Correo para solicitudes de privacidad y eliminación: vozrecep@gmail.com.

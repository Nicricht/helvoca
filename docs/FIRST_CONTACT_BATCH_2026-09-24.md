## Después de cada contacto real

Actualizar `docs/FIRST_PROSPECTS_TRACKER.csv` inmediatamente después de cada contacto real:

- `NEW -> CONTACTED` solo cuando el contacto realmente ocurrió;
- `CONTACTED -> QUALIFIED` solo si el prospecto confirmó un problema real y existe encaje con Helvoca;
- `QUALIFIED -> DEMO` solo si aceptó una demo;
- registrar `main_objection` cuando aparezca una objeción concreta;
- registrar `requested_changes` cuando el prospecto pida una función, ajuste o adaptación;
- sustituir `follow_up_date` por la fecha real acordada para el siguiente paso;
- mantener `first_contact_date` vacío hasta que el primer contacto ocurra realmente;
- no considerar una respuesta cordial como calificación automática.

La meta del lote es obtener información comercial real y un siguiente paso verificable, sin inventar necesidades, interés, reuniones, pilotos ni clientes.

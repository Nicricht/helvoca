## Después de cada contacto real

Actualizar `docs/FIRST_PROSPECTS_TRACKER.csv` inmediatamente:

- `NEW -> CONTACTED` solo si el contacto realmente ocurrió;
- `CONTACTED -> QUALIFIED` solo si confirmó un problema real y encaje;
- `QUALIFIED -> DEMO` solo si aceptó ver una demo;
- registrar `main_objection` cuando aparezca una objeción concreta;
- registrar `requested_changes` si pide una función o adaptación;
- reemplazar `follow_up_date` por la fecha acordada para el siguiente paso;
- no considerar una respuesta cordial como calificación automática.

La meta del lote es obtener información comercial real y cerrar un siguiente paso concreto sin inventar interés ni necesidades.

## Después de cada contacto real

Actualizar `docs/FIRST_PROSPECTS_TRACKER.csv` inmediatamente:

- `NEW -> CONTACTED` solo si el contacto realmente ocurrió;
- `CONTACTED -> QUALIFIED` solo si el prospecto confirmó un problema y encaje;
- `QUALIFIED -> DEMO` solo si aceptó ver una demo;
- registrar `main_objection` si aparece una objeción concreta;
- registrar `requested_changes` si pide una función o cambio;
- reemplazar `follow_up_date` por la fecha acordada para el siguiente paso;
- no usar `notes` para esconder una objeción o solicitud que tenga campo propio.

La meta del lote es conseguir información comercial real y un siguiente paso concreto. No convertir silencio, cortesía o una pregunta en interés inventado.
